# V6 — Project-First System (check-in edition)

This repo runs Naveen's project-first upskilling system. **v6 started 2026-08-31 = day 001.**
Older artifacts live in `archive/` (`pre-v5/` = the v2–v4 curriculum era, `v5-aug-2026/` = the
one-week v5 commit-tracking era).

## How it works

Two monthly tracks, defined in `projects/CURRENT.md` (the single source of truth):

- **INFRA** — a portfolio-worthy AI-infrastructure project that reads as senior-level
  systems work (measured numbers, benchmarks, tradeoffs, upstream OSS contributions).
- **VENTURE** — a revenue-aimed product, launched publicly to get real users, chosen only
  from validated paying demand (direct complaint quotes, competitor pricing, honest
  anti-signals) and shaped differently from incumbents.

A cloud routine fires every morning at 7:00 IST and:

1. Reads `projects/CURRENT.md` (tracks with `Month:` labels, weekly ships with Sunday due
   dates, Status) and `PROGRESS.md` (taught topics, skill gaps, dated progress log).
2. When a track is empty or its month ends: fresh market scan → 3 scored ideas → adopts
   its recommendation the same run (Naveen overrides by replying in the run's chat or
   editing `projects/`).
3. Teaches 1–2 just-in-time topics (~700–1,000 words) that unblock the nearest milestone,
   each ending "Apply it today:", plus a 🚢 Ship This block and a ≤3-bullet market pulse.
4. **Ends with a 📥 Check-in** — 2–4 specific questions about yesterday's reality. Naveen
   replies in the run's chat; the coach asks pointed follow-ups until status is concrete,
   then updates CURRENT.md Status + the PROGRESS.md progress log.
5. Saves the brief to `days/day-NNN-<slug>.md`. **Day number is stateless:** days since
   2026-08-31 + 1 — never derived from file counts.

**No gamification and no commit surveillance:** progress facts come only from Naveen's own
check-in reports. Nothing is invented, estimated, or extrapolated.

# V5 — Project-First System

This repo runs Naveen's project-first upskilling system (v5, started 2026-08-24). The old
curriculum system (v2–v4: ROADMAP/COACH/reviews/my-progress) is archived in `archive/pre-v5/`.

## How it works

Two monthly tracks, defined in `projects/CURRENT.md` (the single source of truth):

- **INFRA** — a portfolio-worthy AI-infrastructure project that reads as senior-level
  systems work (measured numbers, benchmarks, tradeoffs, upstream OSS contributions).
- **VENTURE** — a revenue-aimed product, launched publicly to get real users, chosen
  only from validated paying demand (direct complaint quotes, competitor pricing,
  honest anti-signals) and shaped differently from incumbents.

A cloud routine fires every morning at 7:00 IST and:

1. **Commit check** — reads Naveen's actual GitHub activity on both tracks' repos
   (public events API; token-authed reads for a private venture repo). Progress is
   proven by commits and launches only — no journaling, no gamification.
2. **Project engine** — tracks milestones in CURRENT.md; when a track is empty or its
   month ends, runs a fresh market scan and proposes 3 scored ideas (auto-adopts its
   recommendation after 24h unless Naveen commits a change under `projects/` — his
   commits there are the decision channel). Mondays it defines the week's two ships.
3. **Accountability** — plain facts: per-track commits, ship status. 3+ dead days on a
   track collapses its coaching to one 20-minute re-entry task.
4. **Teach** — 1–2 just-in-time topics (~700–1,000 words) that unblock the nearest
   milestone, each ending "Apply it today:", plus a 🚢 Ship This block (10–15 min per
   track) and a ≤3-bullet verified market pulse.
5. **Save** — the brief lands in `days/day-NNN-<slug>.md` (numbering restarted at 001;
   count excludes `archive/`), PROGRESS.md tracks the day counter, taught topics, and
   flagged gaps.

Target profile the system builds toward: the **infra-literate product engineer** —
evals, serving, cost/latency, reliability on top of un-bootcampable systems depth.
